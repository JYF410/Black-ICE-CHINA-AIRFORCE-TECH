# 定版配置快照（v1.0.0）

## 版本与依赖

| 项 | 值 |
|---|---|
| `config.MOD_VERSION` | `1.0.0` |
| `descriptor.mod` 依赖 | 黑冰本体 `1851181613`、BIAD `3808452657`、坦克子模 `3463196432`（可选） |
| `supported_version` | `1.20.*` |

- **必需**：黑冰本体 + BIAD；
- **可选**：坦克子模（启用时才会出现中国坦克页；不启用时本模组照常工作）。

## 已知限制（接受现状）

1. 中国会同时看到「中国空军」和「通用空军」两个空军页——隐藏通用空军页会让科研界面打不开（R1）；
2. 坦克页/空军页**第一次打开**可能缺图标和连线，存档读档一次恢复（R12），
   开局有 `news_event` 提示玩家；
3. 坦克科技页由坦克子模提供，本模组只负责在开局授予 `CHI_armor`，**不覆盖**它的文件夹定义（R7）；
4. 事件配图必须用 `news_event`，普通事件窗口显示不了图片（R11）。
