# 发布与更新流程

## 1. 构建

工作目录：`D:\Steam\steamapps\workshop\content\394360\中系飞机科技树`

```
python _tools/build/make.py all
```

依次会：

1. 生成 `common/technologies/CHI_air.txt`（76 项科技）
2. 生成 `common/technology_tags/zz_CHI_air_technology.txt`
3. 生成 `common/on_actions/zz_CHI_air_startup.txt`、`zz_CHI_air_array_gen.txt`
4. 生成 `common/scripted_effects/zz_CHI_air_research_arrays.txt`
5. 生成 `common/scripted_guis/BI_tech_queue_china_air.txt`、`events/zz_CHI_air_tip.txt`、空占位覆盖文件
6. 生成 `interface/chi_air_technology.gfx`、`interface/countrytechtreeview.gui`（基于坦克子模 gui 合并）
7. 生成本地化、`descriptor.mod`、`build_info.txt`
8. 最后自动跑 `_tools/validate.py`

看到 `error: 0  warn: 0` 才算过。

单独跑校验：`python _tools/validate.py`

## 2. 打包

```
python _tools/package_diag.py
```

产物：

- `_install/update_game_files.zip` —— 正式更新包（`common/ interface/ gfx/ localisation/ history/ events/` + `build_info.txt`）
- `_install/update_game_files_diagB.zip` —— 排查用的"UI 剥离"包，平时不用

## 3. 更新游戏副本

游戏加载的是 **工坊副本**：

```
D:\Steam\steamapps\workshop\content\394360\3844078670
```

两种方式任选：

- 把 `update_game_files.zip` 解压覆盖到上述目录；
- 或者在启动器里重新发布（会把工作区内容同步过去）。

**验证**：覆盖后检查副本里的 `build_info.txt`：

```
version : 1.0.0
built   : <时间>
```

版本/时间对不上 = 更新没生效，别急着进游戏排查功能。

## 4. 绝对不要做的事

- 不要修改 `Documents\Paradox Interactive\Hearts of Iron IV\mod\*.mod`
- 不要修改 `Documents\Paradox Interactive\Hearts of Iron IV\dlc_load.json`
- 不要 `replace_path` 整个目录
- 不要覆盖父模组（黑冰/BIAD/坦克子模）的**文件夹注册**（见雷区 R7）
- 不要在 `technology_folders.available` 里用会中途变化的条件（见雷区 R1）

## 5. 诊断开关（`_tools/build/config.py`）

改完记得构建前恢复，否则会发布出错版本：

| 开关 | 默认 | 作用 |
|---|---|---|
| `HIDE_GENERIC_AIR` | `False` | 设为 True 会隐藏通用空军页，**实测会让科研界面打不开**，不要开 |
| `REQUEST_GATE` | `False` | 旧的「+ 请求页」方案，已废弃 |
| `GUI_MINIMAL` | `False` | 诊断用：原样输出坦克子模 gui，会缺失中国空军页，**发布必须 False** |
| `ARMOR_TT_FIX` | `True` | 保留装甲请求提示的 hidden_trigger 修正（实际面板覆盖已停用，此开关目前只影响占位文件生成） |

## 6. 更新工坊说明时建议写的内容

- 需要：黑冰本体 + BIAD；
- 可选：中国坦克科技子模（启用后坦克页会出现）；
- 已知现象：第一次打开新科技页可能缺图标/连线，**存档读档一次**即可（游戏内第 1 天会有提示弹窗）；
- 中国会同时有「中国空军」与「通用空军」两个空军页（这是为了界面稳定所做的取舍）。
