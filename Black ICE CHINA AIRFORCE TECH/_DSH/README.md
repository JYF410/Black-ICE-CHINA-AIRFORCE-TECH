# _DSH —— 维护者笔记

这个目录**不参与游戏加载**（不在 `common/ interface/ gfx/ localisation/ history/ events/` 里），
是给以后维护这个模组的人（包括 AI 助手）看的经验记录。

## 目录

| 文件 | 内容 |
|---|---|
| `科研UI雷区与经验.md` | 黑冰科研界面（科技页）的机制、踩过的坑、绝对不要做的事 |
| `定版配置快照.md` | 当前定版（v1.0.0）的完整配置：文件职责、标志、坐标、依赖 |
| `发布与更新流程.md` | 构建、校验、打包、更新工坊副本的步骤与注意事项 |

## 给 AI 助手的三条硬规则

1. **先读 `科研UI雷区与经验.md` 再动科研界面相关文件**——那里记录的问题都真实发生过，
   每一条都至少浪费过一轮"改完进游戏测"。
2. **一次只改一个变量**，并保留一个已知能打开的版本作为回退点（见"定版配置快照"）。
3. **不要碰** `Documents/Paradox Interactive/Hearts of Iron IV/mod/*.mod` 和 `dlc_load.json`；
   发布与启用由用户手动完成。
